# 06 — Add minimal anonymous analytics

**What to build:** Measure whether people use the core conversation flow while preserving the accountless, ephemeral nature of the product and avoiding collection of conversation content.

**Blocked by:** 03 — Complete the question package flow.

**Status:** ready-for-agent

- [ ] Analytics can count started conversation sessions.
- [ ] Analytics can count selected categories and skipped question cards.
- [ ] No question text, regenerated content, session history, personal identifier, or free-form input is collected.
- [ ] Analytics failures never block or interrupt a conversation session.
- [ ] Collected event names and fields are documented and verified against the privacy boundary.
- [ ] The feature can be disabled without changing the core conversation flow.
